# Проверка выпуска 1.0.1

Проверено на Windows 11 x64, .NET Framework 4.8.

- Сборка штатным компилятором .NET Framework без предупреждений.
- Проверки логики: отсчёт по сроку окончания, пауза, сброс, однократное срабатывание, пробуждение после истечения времени, расписание будильников, пропуск выходных, повторение, старые сигналы, откладывание, летнее время и все доступные города, атомарная запись, восстановление, повреждённые настройки, формат и границы длительности. Проверено чтение старых настроек с `Background=true`: режим трея больше не применяется.
- Проверки WPF: старт/пауза и быстрый таймер, диалоги создания и удаления, отклонение неверного времени, повторяющийся будильник, поиск/добавление/удаление города, секундомер и круги, смена фокуса и перерыва, отрисовка всех разделов и компактного окна. Сворачивание и восстановление существующего окна, закрытие красной кнопкой с сохранением настроек и завершением процесса, повторный запуск.
- Установка отдельного тестового AppId в путь с кириллицей и пробелами, проверка хешей, регистрации удаления и ярлыков, повторная установка, запуск проверок установленного EXE, удаление с сохранением пользовательских файлов.

Проверки доступны в исходниках. Отчёты создаются в `test-results` и `.tools`, пользовательские настройки в них не используются. Снимки интерфейса — в этой папке.

Слышимость сигнала зависит от системной громкости и схемы звуков Windows. Пробуждение компьютера и автоматический запуск вместе с Windows не реализованы.

Для версии 1.0.2 проверены прозрачные углы и непрозрачный циферблат всех семи размеров ICO (16, 24, 32, 48, 64, 128, 256), визуальный вид увеличенной иконки и сборка EXE/установщика. Функциональность часов не менялась.
