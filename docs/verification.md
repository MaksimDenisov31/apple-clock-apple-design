# Проверка выпуска 1.0.0

Проверено на Windows 11 x64, .NET Framework 4.8.

- Сборка штатным компилятором .NET Framework без предупреждений.
- 20 проверок логики: отсчёт по сроку окончания, пауза, сброс, однократное срабатывание, пробуждение после истечения времени, расписание будильников, пропуск выходных, повторение, старые сигналы, откладывание, летнее время и все доступные города, атомарная запись, восстановление, повреждённые настройки, формат и границы длительности.
- 22 проверки WPF: старт/пауза и быстрый таймер, диалоги создания и удаления, отклонение неверного времени, повторяющийся будильник, поиск/добавление/удаление города, секундомер и круги, смена фокуса и перерыва, отрисовка всех разделов и компактного окна.
- Установка отдельного тестового AppId в путь с кириллицей и пробелами, проверка хешей, регистрации удаления и ярлыков, повторная установка, запуск проверок установленного EXE, удаление с сохранением пользовательских файлов.

Проверки доступны в исходниках. Отчёты создаются в `test-results` и `.tools`, пользовательские настройки в них не используются. Снимки интерфейса — в этой папке.

Слышимость сигнала зависит от системной громкости и схемы звуков Windows. Пробуждение компьютера и автоматический запуск вместе с Windows не реализованы.
