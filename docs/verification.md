# Проверка выпуска 1.0.5

Проверено на Windows 11 x64, .NET Framework 4.8.

- Сборка штатным компилятором .NET Framework без предупреждений.
- Проверки логики: отсчёт по сроку окончания, пауза, сброс, однократное срабатывание, пробуждение после истечения времени, расписание будильников, пропуск выходных, повторение, старые сигналы, откладывание, летнее время и все доступные города, атомарная запись, восстановление, повреждённые настройки, формат и границы длительности. Проверено чтение старых настроек с `Background=true`: режим трея больше не применяется.
- Проверки WPF: старт/пауза и быстрый таймер, диалоги создания и удаления, отклонение неверного времени, повторяющийся будильник, поиск/добавление/удаление города, секундомер и круги, смена фокуса и перерыва, отрисовка всех разделов и компактного окна. Сворачивание и восстановление существующего окна, закрытие красной кнопкой с сохранением настроек и завершением процесса, повторный запуск.
- Установка отдельного тестового AppId в путь с кириллицей и пробелами, проверка хешей, регистрации удаления и ярлыков, повторная установка, запуск проверок установленного EXE, удаление с сохранением пользовательских файлов.

Проверки доступны в исходниках. Отчёты создаются в `test-results` и `.tools`, пользовательские настройки в них не используются. Снимки интерфейса — в этой папке.

Слышимость встроенного перезвона зависит от системной громкости и выбранного аудиоустройства. Пробуждение компьютера и автоматический запуск вместе с Windows не реализованы.

Для версии 1.0.2 проверены прозрачные углы и непрозрачный циферблат всех семи размеров ICO (16, 24, 32, 48, 64, 128, 256), визуальный вид увеличенной иконки и сборка EXE/установщика. Функциональность часов не менялась.

Для версии 1.0.3 проверены загрузка встроенного WAV, настойчивое уведомление без крестика, отмена закрытия через Alt+F4/панель задач и сворачивания, фактический порядок Win32-окон поверх другого topmost-окна в безрамочном полноэкранном режиме, отсутствие повторных уведомлений об одном таймере, два одновременных таймера, сброс только после «Остановить», независимая остановка сигналов, откладывание будильника, отключённый звук и очистка уведомлений/аудио при полном выходе. Дополнительная проверка длительностью 65 секунд подтверждает отсутствие прежнего минутного ограничения. Автоматические проверки сигналов беззвучны.

Эксклюзивные полноэкранные игры, UAC и защищённый рабочий стол не проверялись и не поддерживают гарантированный вывод поверх них. Нативный тест моделирует полноэкранное окно без рамки; он не означает проверку всех игр.

Для версии 1.0.4 проверены отсутствие стандартного заголовка Windows в редакторе таймера, кнопки +10/−10 секунд, переходы через минуту и час, нижняя/верхняя границы, восстановление корректного ввода и отмена несохранённых изменений. Снимок: preview-timer-editor.png.

Для версии 1.0.5 проверены сохранение громкости и шага, загрузка старых настроек со значениями по умолчанию, реальное масштабирование PCM-сэмплов и тишина при 0%, применение ползунка к аудиопроигрывателю, изменение громкости активного сигнала, сохранение произвольного шага и отклонение неверного значения, использование своего шага в обоих направлениях. Для редактора проверены рамка/тень и результат нативного WM_NCHITTEST (HTCAPTION) на верхней панели. Проверено отображение секунд и текущей даты в боковой панели. Снимки: preview-settings.png, preview-timer-editor.png.

Для версии 1.0.6 проверены стрелки +1/−1 секунды в настройке шага, границы 1/3600, пустой ввод, отсутствие сохранения до «Применить шаг» и сохранение значения после применения.
