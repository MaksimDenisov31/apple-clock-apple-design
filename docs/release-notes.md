Обновлены полосы прокрутки в стиле macOS.

- Тонкий скруглённый бегунок без стандартных стрелок Windows и фоновой полосы.
- Цвета для светлой и тёмной тем, выделение при наведении и перетаскивании.
- Сохранены прокрутка колёсиком, перетаскивание бегунка и нажатие на свободную область для прокрутки страницы.
- Оформление применяется ко всем полосам прокрутки приложения, включая диалоги.

Скачать `AppleClock-Setup-1.0.7.exe` или `AppleClock-Portable-1.0.7.zip`. Настройки сохраняются при обновлении.
