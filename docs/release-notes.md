Первый выпуск Apple Clock — Apple Design для Windows 10/11.

- Таймеры с круговым отсчётом и быстрым запуском.
- Будильники с повторением по дням недели и откладыванием на 5 минут.
- Секундомер с кругами, мировые часы и фокусировка с перерывами.
- Светлая и тёмная темы, работа в трее, локальное сохранение.

**Скачать:** `AppleClock-Setup-1.0.0.exe` для установки или `AppleClock-Portable-1.0.0.zip` для запуска без установки. Требуется .NET Framework 4.8. Контрольные суммы — в `SHA256SUMS.txt`.

Сигналы работают при открытом приложении или в трее и бодрствующем компьютере. Часы не будят компьютер и не запускаются автоматически вместе с Windows. Секундомер работает до полного завершения приложения.

Проверены логика времени и сохранения, интерфейс WPF, установка, повторная установка и удаление. Подробности — в README репозитория.
